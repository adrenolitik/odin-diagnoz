# Один диагноз

Симуляция болезни: диагноз выпадает по реальной статистике — пол, возраст начала и страна берутся из данных, а не из пожеланий. Вы проживаете эту жизнь до конца, с пятью паузами там, где жизнь действительно делает выбор. Рядом идут четыре такие же жизни в других странах: тот же диагноз, другой доступ к помощи.

Всё в одном файле `index.html` — без зависимостей, сборки и сервера.

**Открыть:** https://adrenolitik.github.io/odin-diagnoz/

## Данные

Приблизительные опубликованные оценки: ВОЗ (неинфекционные заболевания, 2019–2023), GLOBOCAN / IARC (2022), GBD 2019, IDF 2021, UNAIDS 2023, MSIF 2020.

## Оговорка

Это образовательная модель, а не прогноз и не медицинская рекомендация. Течение болезней упрощено, цифры округлены. Если вас беспокоит собственное здоровье — это повод пойти к врачу, а не прожить это здесь.
